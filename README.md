## ⚙️ Project Functionality & User Experience

The Image Gallery provides a simple, responsive, and interactive experience where users can explore and manage images easily.

### 1. 🔍 Category Filtering

Users can select different categories:

- 🌿 Nature
- 🐾 Animals
- ✈️ Travel
- 🍴 Food
- 🔍 All

When a category is selected, the gallery displays images belonging to that category.

### 2. 🖼️ Image Preview

Clicking on an image opens it in a larger **Lightbox Preview**.

Users can view the selected image along with its title, description, and information.

### 3. ⬅️➡️ Previous and Next Navigation

Inside the image preview, users can navigate between images using:

- ⬅️ Previous button
- ➡️ Next button

### 4. 🎨 Image Filters

Users can apply different visual effects:

- **Original** – Displays the image normally.
- **Bright** – Increases image brightness.
- **Grayscale** – Converts the image to grayscale.
- **Sepia** – Applies a sepia effect.
- **Contrast** – Increases image contrast.

### 5. ❤️ Like Function

Users can click the **Like** button to interact with the selected image.

### 6. 📥 Download Function

The **Download** option allows users to download the selected image.

### 7. 🔗 Share Function

The **Share** option allows users to share the selected image when browser sharing is supported.

### 8. ⌨️ Keyboard Navigation

Users can navigate through the image preview using keyboard controls:

- **Left Arrow** → Previous image
- **Right Arrow** → Next image
- **Escape** → Close image preview

### 9. 📱 Responsive Design

The gallery is designed to work across different screen sizes:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📱 Tablet

### 10. 🚀 User Experience

Users can easily:

1. Open the Image Gallery.
2. Select an image category.
3. Browse the available images.
4. Click an image to open the preview.
5. Navigate between images.
6. Apply different image filters.
7. Like, share, or download images.

The project focuses on providing a **clean, responsive, interactive, and user-friendly image browsing experience**.
